# Design Studio Website

A professional, modern website for a design business offering web design, logo design, ad creation, label design, and flyer design services.

## Features

✨ **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

🎨 **Modern UI** - Beautiful gradient colors and smooth animations

📱 **Mobile Menu** - Hamburger navigation for smaller screens

🔍 **SEO Friendly** - Semantic HTML and proper meta tags

⚡ **Fast Loading** - Optimized CSS and lightweight JavaScript

📧 **Contact Form** - Fully functional contact form for client inquiries

📰 **Newsletter** - Newsletter subscription form in footer

🎯 **Service Showcase** - Detailed service cards with icons

🖼️ **Portfolio Section** - Display your design work and projects

🔗 **Social Links** - Links to social media profiles

## Sections

1. **Navigation Bar** - Sticky header with smooth scrolling links
2. **Hero Section** - Eye-catching introduction with call-to-action buttons
3. **Services** - 6 key service offerings with icons and descriptions
4. **Portfolio** - Featured project showcase
5. **About** - Company benefits and features
6. **Contact** - Contact information and inquiry form
7. **Footer** - Links, social media, and newsletter signup

## Installation

1. Clone the repository
```bash
git clone https://github.com/Emmanuel-Franklin1/design-studio-website.git
```

2. Navigate to the project directory
```bash
cd design-studio-website
```

3. Open `index.html` in your web browser

## Customization

### Update Contact Information
Edit the following in `index.html`:
- Email address
- Phone number
- Business location
- Business hours

### Customize Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --accent-color: #f59e0b;
    /* ... more colors ... */
}
```

### Add Your Portfolio Images
Replace the placeholder icons in the portfolio section with real project images.

### Update Service Descriptions
Modify the service cards text to match your actual services and offerings.

## Deployment

### Deploy to GitHub Pages
1. Push changes to main branch
2. Go to Settings → Pages
3. Select "main" branch as source
4. Your site will be available at `https://username.github.io/design-studio-website`

### Deploy to Other Platforms
- **Netlify**: Connect your GitHub repo and deploy automatically
- **Vercel**: Push to GitHub and connect to Vercel
- **Traditional Hosting**: Upload files via FTP to your web server
